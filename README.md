# ZYRA

A scalable and secure backend architecture for a digital products e-commerce platform, featuring modular design and automated deployment workflows.

## 🚀 Overview
ZYRA is a scalable and secure backend solution for a digital product marketplace, designed to efficiently manage product inventory, secure transactions, and user data using a clean, modular architecture.

Built with **Flask** and **PostgreSQL**, this repository demonstrates my proficiency in building robust, production-ready APIs while maintaining clean code standards.

## 🌐 Live Demo
You can access the live version of ZYRA here: [https://zyra-fc2n.onrender.com](https://zyra-fc2n.onrender.com)

## 🛠 Tech Stack
* **Language:** Python 
* **Framework:** Flask (Modular architecture via Blueprints)
* **Database:** PostgreSQL (with SQLAlchemy ORM)
* **Migrations:** Alembic
* **Testing:** Pytest (Unit testing)
* **Containerization:** Docker & Docker Compose

## 🔑 Key Engineering Highlights
* **Modular Architecture:** Utilized **Flask Blueprints** to ensure the codebase remains scalable, maintainable, and easy to extend for new features.
* **DevOps Ready:** Fully containerized with **Docker**, eliminating "it works on my machine" issues and streamlining deployment workflows.
* **Data Integrity:** Managed database schemas using **Alembic migrations**, ensuring reliable version control for database changes.
* **Quality Assurance:** Developed comprehensive **unit tests using Pytest** to achieve high code coverage and minimize bugs during the development lifecycle.
